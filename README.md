# 🍔 Fast-Food Reverse-Engineering Lab Dashboard

An AI/ML-driven interactive Streamlit dashboard that reverse-engineers fast-food nutritional data, predicts total calories, sodium, and thermic effects using Multiple Linear Regression, and estimates exercise burn times (Walking, Running, HIIT).

## 🚀 Features
- **Nutritional Reverse Engineering**: Predicts total calories ($R^2 = 0.9990$) based on macronutrients.
- **Exercise Burn Time Estimation**: Calculates exact burn times for Walking, Running, and HIIT based on consumer weight.
- **Interactive Customization**: Simulate additions (Fats, Carbs, Proteins) in real-time.
- **No-Overfitting Validation**: Evaluated via 80/20 Train/Test split.

## 🛠️ Tech Stack
- **Python**, **Streamlit**, **Pandas**, **NumPy**
- **Scikit-Learn** (Multiple Linear Regression)
- **Plotly**
